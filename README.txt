# Green Creative Portfolio

A free, responsive portfolio inspired by the supplied screenshot.

## Files
- index.html — page structure/content
- style.css — responsive green/black visual design
- script.js — cursor glow + scroll reveal animation

## Customize
Open index.html and replace:
- Safin Riyasa
- description
- project names
- email address
- years/statistics

No paid libraries are required. Google Fonts is used for Inter.

## Free hosting
Upload these files to a GitHub repository and enable GitHub Pages in:
Settings → Pages → Deploy from branch → main → /(root)
